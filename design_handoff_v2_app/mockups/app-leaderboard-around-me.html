On scope change
Re-rank within scope · %-bar rescales to the scoped leader’s API (same agent reads longer under My Unit) · subtitle updates with field + count · around-me recomputes · persist last scope like the period chip.
No conflicts

Nothing here changes the live podium. Podium [#2, #1, #3] order, tail counts (4–8 desktop / 4–7 mobile), YTD default, the api/maxApi %-of-leader bar, and branch-default scope are all preserved. Around-me is additive (footer / sticky bar). Scope only changes which entry is maxApi when narrowed. One net-new field: previousRank for the movement chip — ship without it rather than fake it.
