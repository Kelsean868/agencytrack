Monthly Recruiting v2 — build the bench through an 8-stage pipeline

Recruiting new advisors. Anyone can refer a prospect; the manager owns the pipeline and moves candidates through eight stages — Sourced → Contacted → Career seminar → Interview → Assessment → Offer/contracted → In licensing → Licensed & active. Only the last stage counts as a hire, and it feeds the Recruiting KPI on the Weekly WAR. The target is configurable and runs monthly or quarterly — today's guidance is "at least 1 licensed advisor per quarter", so the surface reads gracefully with a soft minimum (and could show "no target set"). Surfaces: quarterly target + funnel stats, a kanban pipeline board, and a candidate drawer (stage timeline, referrer/owner, advance stage). Desktop light + dark, plus mobile. Teal = pipeline · gold = offer→hire.
