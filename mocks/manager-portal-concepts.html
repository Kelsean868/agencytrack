Manager Portal Concepts

Visual reference for the manager-portal redesign approved on 2026-05-11. Extends the agent-portal Track B v2 design language ("Concept 4 Complete") to manager surfaces — same Nexus tokens, same primitives, denser information for orchestrators. Each frame below is rendered with the project's actual --color-* tokens, Cabinet Grotesk + Satoshi typography, and 44pt touch targets.

Toggle theme and device above. Four screens are in scope here: Manager Overview (the anchor), Goals (IA flatten), Persistency (cohesion polish), and Awards (medal-system alignment). Production Report, Master Sheet, and Compliance ship per recommendations.md without dedicated mocks — they're already cohesive enough that source-level guidance suffices.

P0 highest impact   P1 important polish   P2 cosmetic / token cleanup

Manager Overview

P0 · Large

Replaces the current legacy MotivationalCarousel + custom progress bar + 4 hardcoded StatCards with a Track B v2-shaped hero: .role-hero donut + 4-item KPICard sparkline strip + W/W pulse pills + g4-mix activity feed + team award medallions. Real Firestore reads replace the placeholders as part of this PR.
