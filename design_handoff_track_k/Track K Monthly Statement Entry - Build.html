Data canon

One flat doc per month. Writes financing/{agentId}_{YYYY_MM} with financingPaid, netCommission, bonusOffset, runningBalance + notes (all parseFloat). The statement's runningBalance is authoritative — it overrides any client-side roll-forward, may be negative (= owed back to the agent), and self-corrects drift. The month also stores the validatingAPI / actualAPI in effect + the basisSource. A missing month is reconciliation-flagged, never auto-filled.

1
Running balance is stored, not rolled
LOCKED (§6): runningBalance is written from the statement and is authoritative. The UI may show a client roll-forward estimate for sanity, but the typed statement value is what persists — self-correcting, drift-proof, and the single source the dashboard ceiling reads.
2
Negative balance is a first-class value
The authoritative field accepts a negative number = surplus owed back to the agent. No validation blocks it; the dashboard renders it left-of-zero in green. It is never treated as an error or clamped to zero.
3
Four figures + month-in-effect context
financingPaid · netCommission · bonusOffset · runningBalance, all parseFloat. The save also stamps the validatingAPI / actualAPI in effect and the basisSource so the month is self-describing for later reconciliation.
4
Skipped month → reconciliation flag, not interpolation
LOCKED: a missing monthly doc is flagged, never auto-filled. Interpolating a gap would distort the balance and ceiling. The flag persists until the month is entered or explicitly carried (with a note) into the reconciliation record.
5
Restyle of the manager-wins entry drawer
This is the Persistency-v2 entry-drawer pattern re-pointed at the financing ledger: gold precedence banner, solid ≥44px fields, Save. Same write discipline (manager value authoritative), new target collection.
6
Audit fields on every write
enteredBy / enteredByName / enteredAt / source stamp each save — the same audit shape the persistency and settlement writes use. The notes field is the human trail for a corrected or reissued statement.
