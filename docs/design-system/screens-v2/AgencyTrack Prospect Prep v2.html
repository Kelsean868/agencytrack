Prospect Prep v2 — "prep for this joint call", not a CRM

The repo's appointment-bound Joint-Call Prep (agent-authored, manager-readable), reframed from a flat form-list into a prep tool. A next-call hero with countdown + readiness (amber when imminent & unprepped), the four objections turned from dead checkboxes into a rehearsal aid (what each means + how to counter), a bottom-sheet new-prep flow, a clean manager read-only view for the joint call, and a quiet prep → policy convert moment. Mobile-first + a desktop layout.
