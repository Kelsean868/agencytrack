Decision 1 — the percent ‖ direct toggle & what switching preserves
% PERCENTTotal + per-line shares
Agent editsOne total annual API field + a % share per line. Shares must sum to 100% (live-validated; last edited line absorbs rounding).
ComputedEach line's targetAPI = total × pct. The TTD-per-line column is shown read-soft so the agent sees the money, but edits the share.
Good for"I want to earn TTD 600K — split it 70 / 20 / 6 / 4." Top-down from a number the agent already trusts (the seed total).
TTD DIRECTAbsolute API per line
Agent editsAn absolute TTD API field per line. No total field — the total is the sum of the lines and updates live.
Computedpct = targetAPI ÷ Σ targetAPI per line, shown read-soft. The share column flips to display-only in this mode.
Good for"Life is exactly TTD 420K, Property 36K…" Bottom-up when the agent thinks in per-line books, not a blended total.
⇄

Switching preserves the allocation — it converts the representation, never the money. targetAPI per line is authoritative and untouched on a mode switch. % → Direct: drop the total field; each line's existing targetAPI becomes its direct value (totals already match). Direct → %: set total = Σ targetAPI, then pct = targetAPI ÷ total per line. Round display only; keep full precision in the store. The one visible change is which column is editable — the plan itself is identical on both sides of the toggle.

License profile — the gating is a PARAMETER, not a hard-coded A&H side
Composite MARSHA
Full license — all four lines available to allocate. The default when licenseProfile is absent.
LifeA&HPropertyMotor
Life-only
Life lines enabled; general (Property/Motor) disabled. Which side A&H sits on is the parameter.
LifeA&H ?PropertyMotor
General-only
General lines enabled; Life disabled. A&H is the mirror of the Life-only call — set once, consistently.
LifeA&H ?PropertyMotor
⚑

A&H's side is a single config value, surfaced — not baked in. The gate is a map profile → enabled[]: Composite = all four; Life-only / General-only each enable their own side plus or minus A&H per one parameter (ahSide: 'life' | 'general'). Kyron settles it at brief time; the UI reads the parameter so flipping it never touches layout. Disabled lines render greyed with their toggle off and are excluded from the total, share math, and award API.
