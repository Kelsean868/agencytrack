Your committed goal → what it earns.

One new section for the agent Goals tab, sitting directly below GapAnalysisPanel (the CommitmentHero + production cascade). It translates the agent's committed production goal into the income it generates — committed API goal × the blended commission rate = estimated annual income (TTD), with an honest assumptions note. Derived & display-only: no input, no set-income-target (that's a separate privacy decision). Reuses the Commission Playground math already in the app. Awards + MDRT are later phases — this sheet designs only the derived-income readout.

Reads as a sentence: goal → rate → income · NEW
The section is one left-to-right equation — committed API goal × blended rate = estimated annual income — so the agent sees why the number is what it is, not a bare figure. The × / = operators are real glyphs, and the result lands in its own teal pane with hero ink kept inside it.

No new data — reuses what's wired · EXISTING
Committed API comes from the same Personal Commitment GapAnalysisPanel renders; the rate + conversion are the Commission Playground math already in the app. This section is a second read of existing values — there's no second model and nothing to fetch beyond what the tab already has.
3
Display-only — no input, no income target · NEW
There is no field and no "set income target" here. The agent edits production (in Game Plan); income is purely derived. Setting an income target is a separate privacy decision for a later phase — this section deliberately doesn't open that door.
4
Honest assumptions, stated up front · doctrine
The note is honest by default: one blended rate (not per-line), an explicit settlement basis, renewals/clawbacks excluded, and "estimate, not a guarantee." The two side cards (per-month, earned-YTD) are clearly est. — never dressed as booked income.
