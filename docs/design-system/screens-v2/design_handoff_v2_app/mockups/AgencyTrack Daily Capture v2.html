Daily Capture v2 — mode-aware quick log + reporting-mode governance

The mobile-first daily logger behind the Submit FAB. A per-day entry using the full weekly field set (steppers for counts, compact money inputs), anchored in today + week-to-date vs target with a logging streak. Agents pick their reporting mode (daily / weekly / hybrid) — switching mid-week is safe (daily rolls into the weekly draft; weekly converts to a catch-up entry). Managers set mode down the hierarchy with recommend vs lock + provenance, over a tenant-admin company default. A streak milestone fires the recognition grammar.
