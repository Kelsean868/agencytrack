Settings v2 — one home for every customization, role-scoped

Consolidates the app's scattered customizations into one surface (off the avatar menu). My Preferences are personal; Team Defaults let a manager set defaults for the levels beneath them — recommend (overridable) or lock (read-only below), reusing the recommend-vs-lock grammar from Goals. Settings resolve down the hierarchy Company → SM → Branch → Unit → Agent; rows locked above show greyed with provenance. In-context Tweaks still work — they write the same value. Branch-manager + agent views, light + dark + mobile.
