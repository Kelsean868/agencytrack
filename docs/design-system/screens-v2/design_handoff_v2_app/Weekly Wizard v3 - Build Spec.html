Core rule

One wizard, two paths, identical submission. The path is chosen by how the week was captured: loggingMode ∈ {daily, hybrid} → fast path (confirm + reflect); weekly → full path (4 phase screens). Both write the same weeklyReport payload — only the data-entry burden differs. Nothing here changes the submission schema.

Path selection
// Resolved once when the wizard opens. function resolvePath(agent, weekId) { const mode = effectiveLoggingMode(agent, weekId); // daily | hybrid | weekly (existing service) const draft = readWeeklyDraft(weekId); // aggregated from daily (see aggregator spec) const hasDailyData = draft && draft.daysLogged > 0; // fast path only if the mode logs daily AND there's actually data to confirm return (mode !== 'weekly' && hasDailyData) ? 'fast' : 'full'; }
!

The hasDailyData guard is the no-daily fallback. A daily/hybrid agent who logged nothing this week has an empty draft → drops to the full path automatically. No empty confirm screen, no dead end. (Decision 4 — partial-week threshold.)

Open decisions — CC's call
⚑ Resolve against live code
Recommended contract above; these are genuine forks.
1
Inline edit — weekly-level or rewrite the day?
An edit on the confirm screen: store a weekly override, or write back to a specific dailyActivity doc? Lean: weekly-level override — the confirm screen edits the report, not history.
2
Hybrid mode path
Hybrid = daily logging + weekly review. Treat as fast path (confirm) like the mockup, or a middle path that still steps through sales/production? Lean: fast path — hybrid already logged daily.
3
Confirm section granularity
Two combined sections (mockup) vs one per daily card (prospecting / contact / interviews / production / delivery / hours). More sections = more scannable, more scrolling.
4
Partial-week threshold
How many logged days trigger fast vs full? daysLogged > 0, or a minimum (e.g. ≥ 60% of working days)? Below it, full path.
5
Mid-week mode switch
If an agent switches weekly→daily mid-week, does the wizard recompute the path on next open? Lean: yes — path resolves fresh each open from current mode + draft.
