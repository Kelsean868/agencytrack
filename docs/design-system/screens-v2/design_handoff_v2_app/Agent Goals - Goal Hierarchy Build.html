Hero = the agent's own commitment · NEW
The top summary gets hero treatment per the doctrine: the agent's Personal Commitment (TTD 600K) with API, Apps and Persistency each shown vs YTD. Hero ink stays inside the hero pane — white-on-teal in light, lifted-teal surface in dark. Gold hero tokens are retired; legibility is the gate.
2
Cascade reads the hierarchy prop · EXISTING
All five layers come from hierarchy; the YTD bars from ytdTotals. Top→bottom: Company Floor → SM → Branch → Unit → Personal. Each node shows Annual API, the per-layer apps/persistency where relevant, and a YTD progress bar. No new data — a redesign of what's already supplied.
3
Group-key colored dots · TOKEN
Each layer carries a group-key dot: --warning (floor / backstop), --inkAccent violet (SM), --tealLight (Branch), --teal (Unit), and solid teal with a tint ring for the agent's own row. The agent's row is also tint-banded (--tealTint) and full-bleed so "yours" reads instantly.
4
The gap is stated, not left to mental math · NEW
A plain-words readout closes the panel: "your TTD 600K sits 150K above your L4 floor." That's the whole point of a gap panel — make "your committed goal vs the floors above you" immediately legible. Status flips to --warning tone if a commitment ever falls below floor.

One markup, two themes · scoped CSS vars
Dark mode is the same panel under .dark — every color is a --a-* var, so nothing is hand-painted. Hero flips from teal-fill/white-ink to a raised surface with teal border (lifted teal #4AB5B8), keeping hero ink legible without a colored slab. No hex escapes the vars.
6
Mobile = vertical stack, hero first
Below ~640px the hero compresses to a 2-up metric grid and the cascade becomes a vertical list (dot · label · API), the agent's row still tint-banded at the bottom. Apps column drops to keep rows ≥44px tap-legible; the gap note wraps under. Read-only — no controls to reflow.

This panel is where the loop lands. The agent's Personal Commitment is the destination the Game-Plan Commit writes — so the redesign makes "your committed goal vs the floors above you" the whole story: a hero for the commitment, a group-keyed cascade for context, and a plain-words gap for the verdict. It's read-only (the agent edits in Game Plan, not here), honest (below-floor and empty are real states, never faked on-track), and fully tokenized — both themes from one markup, Lucide-only icons, ≥44px rows, TTD throughout, no hex outside the Nexus vars.
