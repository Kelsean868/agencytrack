Annotated surface — 8 markers
1
Header — date + week only
Title Log Today, sub THURSDAY · WK 48, close (✕). Default = date only. Flip D2 adds a reduced week-to-date count strip (APPR/FFI/CI/APPS) — running counts of this week's entries, no targets, no dials, no streak. Week label is derived from today's date (Sunday-anchored), not a picker.
2
Prospecting · teal group card
Four ± steppers: qualifiedApproaches · newNamesAdded (single rollup — kept) · oldNamesWorked · serviceContacts. Header {filled}/{total} = count of fields > 0 (display only).
3
Appointments & FFI · teal
Three steppers: appointmentsSet · ffisScheduled · ffiConducted. Map each to the existing daily key before wiring — verify names against INITIAL_DATA.
4
Interviews · gold
Four steppers: newCIBooked · oldCIBooked · ciConducted · solutionPresentations. Gold accent = production-adjacent grouping.
5
Production · gold — core + disclosure
Visible: newBusinessApps (stepper) + newBusinessAPI (TTD money). Collapsed “PPP increases & lumpsums — optional” holds pppApps / pppApi / lumpsum — matches today's collapsible behaviour.
6
Per-day credit line — DERIVED, display-only
TTD 8.4K credit in the card header is computed client-side from the entered production fields, not a stored field. DECISION: the daily-credit formula isn't drawn — reuse the wizard/Leaderboard credit math so the number agrees across surfaces. If undecided, ship this slice without the credit line rather than guess.
7
Reflection (D1 flip)
Default: collapsed “Reflection (optional)” holding hoursWorked / wins / blockers + a visible note — preserves today's journal fields & the weekly hours feed. Flip → “Note only” drops the block to a single note.
7
Why D1 matters
“Note only” is not free — dropping hoursWorked daily removes the source the weekly Time-Management step aggregates from. Keep the Reflection block unless you've re-homed hours. This is the one flip with an aggregation consequence.
8
Sticky “Save today” — explicit save
Full-width CTA, caption “Rolls into your WK 48 report.” Explicit save (not autosave). Opening today re-opens the existing day's doc pre-filled (one entry per agent per day). No back-fill / past-day picker in this slice.
