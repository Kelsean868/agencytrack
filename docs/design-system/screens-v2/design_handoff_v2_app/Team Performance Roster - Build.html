A consolidated Team Performance roster for Unit & Branch Managers: one row per team member, eight sortable columns, and a granularity + period picker that scopes only the four production columns. Persistency reuses the two-tick band from the Persistency tab; % of annual goal is an annual metric that never moves with the period. Follows the MasterSheet sticky-header / pinned-name table pattern. Light & dark.

A
Period filter — grain + picker, production-only scope
Granularity Year / Month / Week with a matching period picker. Default current year (2026). The selected period scopes only the four production columns via per-agent period GETs. Persistency & % of annual goal do not flow by period.
P
Persistency — reused two-tick band
Current % reflecting the month containing the selected period (latest month on a Year view). Same band grammar as the Persistency tab: fill colored by band + 80 floor / 90 gate ticks. Thresholds are the shipped PERS_FLOOR/PERS_GATE.
G
% of annual goal — annual heat, AA-legible
Full-year YTD submitted API ÷ committed annual target. Subtle heat: ahead-of-pace reads success, behind reads warning, with a faint time-elapsed pace marker. Number stays AA-legible (color is a cue, not the only signal). "—" when no target is committed. Does not change with the period.
S
Sort + pinned Name — MasterSheet pattern
Click a header to sort; click again toggles asc/desc; the active column + direction shows an arrow. Default Name A→Z. Numeric columns right-aligned. Name pinned on horizontal scroll, sticky header — same scaffold as MasterSheet.
T
Tenure — derived, sorts by date
Duration since contractDate rendered as "3y 2m", with the contract date as secondary text. Sorting this column sorts by the underlying date, not the formatted string.
B
Submitted vs Issued — subtly grouped
A quiet group band + a slightly stronger rule between the Submitted and Issued/settled pairs keep the four production columns from reading as a flat wall of numbers — without boxing them.
