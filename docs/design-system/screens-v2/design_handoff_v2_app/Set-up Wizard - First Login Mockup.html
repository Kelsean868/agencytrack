The four central questions — proposed answers
Question 1
Full panel vs. condensed step
Condensed, with an escape hatch. Money Needs & Game Plan get purpose-built lightweight capture — a few inputs to a number — visually consistent with the live tools but stripped for momentum. Each step links out to the full tool for depth. Toggle the control on the Money Needs step to compare both live.
Condensed wins for first-run completion
Question 2
Shell pattern — takeover vs. overlay
Full-screen takeover. A focused shell that previews the destination, rather than an overlay on real screens — which would fight the empty states a new user hasn't populated yet.
Takeover

Question 3
Skip & resume
Skip per step (and skip-the-whole-thing from Welcome → lands in the app). Resume is never lost: progress persists, next login opens a "Welcome back" resume card, and a "Finish setting up" bar rides the dashboard until done. Flip the toolbar to Returning, or Skip from Welcome, to see both.
Never trapped, never restart
Question 4
Completion payoff
The "you're all set" screen summarizes what they just created — agent identity, their Personal Commitment, the goal & gap, derived income, and the pinned stretch award — each tappable to jump back and edit, then drops them into a populated dashboard. The value is felt immediately, not described.
Show the populated product

Identity specifics (pilot): the agent number is an authoritative Tatil-issued value the user transcribes — format 3 digits · 1 letter · 2 digits (synthetic hint 000A00). It's write-once with manager correction later, and validates softly: well-formed shows valid, an off-format value gives a "double-check" warning (not a wall), and a collision shows "already in use." Try typing 000A00 on the Identity step to see the collision state. The wizard is role-agnostic — producing managers onboard the same way. This is a mockup for review; no logic or data design is implied.
