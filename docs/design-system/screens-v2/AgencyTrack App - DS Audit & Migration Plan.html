App DS Audit & Migration Plan

A screen-by-screen read of where the 39 Nexus app surfaces stand against the bound AgencyTrack design system, what has been redesigned but not yet built, and the order to migrate everything onto the canonical _ds component bundle. Agent surfaces are prioritised.

Scope: 39 app screens · Target: _ds bundle + .nexus tokens (app-v2) · Prepared 05 Jul 2026 · Basis: design artefacts in this project

1 · Executive summary

The app exists today as two parallel tracks that have never been reconciled:

  • The composed prototype (AgencyTrack Prototype.html) — one navigable app that wires ~39 screens together. It still runs on throwaway kebab tokens (--primary, .app-root[data-theme]) and Space Mono — the exact conventions the redesign addendum says must not ship.
  • The standalone v2 redesigns (… v2.html, one per feature) — polished, on the warm-neutral palette and correct fonts, but each re-implements the shell and tokens locally via app-tokens.jsx / app-shell.jsx rather than composing the bound system.

Headline finding

0 of 39 screens are built on the bound _ds bundle. The design system now ships the entire app kit — AppShell, Sidebar, SideNavSections, Topbar, Scorecard, GlassCard, StateLayer, EmptyState, ErrorState, SkeletonScreen, CommandPalette, MobileTab/More/CreateSheet, Money, Icon, Eyebrow, Button, Card — plus a ready ui_kits/nexus shell. Every redesign predates it and duplicates that code by hand.

Latent accessibility bug carried by every v2 redesign

The shared app-tokens.jsx still defines light-mode inkFaint: #A8A39C — the pre-fix value that measures ~2.3:1 and fails WCAG 2.2 AA (1.4.3) wherever it carries text (eyebrows, meta, table footers). Canonical app-v2.css fixed this to #7A7264 (~4.7:1) and reserved #A8A39C for non-text (--inkDim) only. This ships broken in every standalone redesign.

What "match the new design system" means, concretely

Tokens
Canonical .nexus / .nexus.dark, camelCase (--teal, --inkMute) from app-v2.css — not the prototype's kebab names.
Components
Compose window.AgencyTrackDesignSystem_ad1cd7 exports; delete the local re-implementations.
Fonts
Local Cabinet Grotesk + Satoshi; mono is JetBrains Mono (retire Space Mono & the Fontshare CDN).
State
Every data surface renders through StateLayer (loading / empty / error) per addendum §1.
A11y
WCAG 2.2 AA floor; the inkFaint fix; focus rings; labelled icon buttons; sectioned nav.

5 · Migration plan

One shell, one token scope, one nav registry — screens plug in as content. Agent surfaces ship first because they carry the daily-active load.

  • Adopt app-v2.css tokens verbatim; delete app-tokens.jsx palette objects and the prototype's kebab tokens.
  • Retire Space Mono & Fontshare; point --mono at JetBrains Mono and load local @font-face.
  • Build the screen/nav registry (role → sections → screen id) once, from the prototype's existing SCREENS map.

Definition of done — per screen

  • Renders inside AppShell on .nexus / .nexus.dark; no local token objects.
  • Data surface wrapped in StateLayer with a matched skeleton, an actionable empty state, and an inline retry error.
  • Numerals tabular + right-aligned; currency via Money; dense tables scroll in-card with sticky header/first-column.
  • One GlassCard max (top summary); gold only for recognition.
  • AA in both themes (incl. the inkFaint fix); focus rings; every icon button labelled; ≥44px mobile targets.
  • Motion gated behind prefers-reduced-motion; visible end-state is the base style; no infinite content loops.
