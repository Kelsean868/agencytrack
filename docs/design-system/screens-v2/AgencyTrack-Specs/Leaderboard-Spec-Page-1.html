DECISION 02

Period chip windows & anchors

Confirm to build

The chips, labels, default (YTD), and "switching a chip re-ranks everyone by that period's reconciled API" are all in the mockup. What's undrawn: the exact window boundaries. The binding rule — these must be the identical windows the production-report / reconciled-ledger engine already uses. One source of truth means the Leaderboard can never define "this month" differently than the Production Report.

DECISION 04

Ranking scope by viewer role

Confirm to build

The mockup draws one field: branch-wide ("South Branch · 28 agents") with unit codes as a column. Undrawn: whether the field changes by viewer, and whether unit / tenant scopes exist. Proposed set below — the agent view is exactly what's mocked; managers gain a scope toggle; cross-branch lives in the Production Report suite, not the gamified podium.

Agent

Their branch board

Branch

Exactly the mockup. One branch field, unit codes shown for context. No scope switch — keeps the surface simple and competitive within the room they work in.

Unit / Branch Mgr

Unit ↔ Branch toggle

UnitBranch

Adds a Unit scope (their team only) alongside the branch default. Lets a UM run their unit's board in a huddle, then zoom to branch standing.

Sales Mgr / CRO

Branch picker

BranchPick ▾Tenant*

Branch board with a branch picker. Cross-branch / tenant-wide ranking belongs in the Production Report's RankedLeaderboard, not this podium.

Confirm

Default scope everywhere = Branch (matches the mockup). Managers get a Unit/Branch toggle; CRO/SM get a branch picker. Tenant-wide stays in the Production Report — the podium is a branch-room motivator, not an org analytics view. *Tenant scope = read-only, SM/CRO only.

DECISION 05

"Around me" — pinned viewer row

Net-new · not in mockup

The mockup shows 8 rows and never highlights the viewer. At a real branch of 28+, most agents fall off the visible list and lose their place. This adds a pinned "You" row with an optional N-1 / N / N+1 cluster — designed in the existing tail row style, using the primary highlight treatment.
