Game Plan v2 — the planning module (renamed from "Looking Ahead")

A real planning hub that builds the agent's year and feeds Goals on commit. Anchored in "your reality" — the commission you must earn — with a jump-able 4-step rail: Money Needs (expense groups → PAYE gross-up → required 1st-year commissions), Year Plan (split that target across license-aware product lines — composite, life-only or general-only — with award-eligibility, % or direct, → API to write), Monthly Plan (12-month target-vs-actual with variance-driven suggestion chips), and Review & Commit (lock → writes your commitment to the Goals page). Draft → committed state throughout. Manager view shows the shared plan with a suggest-back flow.
