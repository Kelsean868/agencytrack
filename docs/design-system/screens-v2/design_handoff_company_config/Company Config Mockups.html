Company Config — the tenant admin's counterpart to Settings v2

One surface where an admin shapes AgencyTrack for the whole company. 12 sections in a grouped left rail (Brand / Standards / Recognition / Operations / Platform) with a teal dot marking customized sections, plus ⌘F find-a-setting that jumps across sections — the find-anything-in-10-seconds answer. Every row speaks one grammar: DEFAULT (inherited, editable) · CUSTOM (teal dot + "changed by · date" + reset) · PLATFORM-MANAGED · HARDCODED · UNLOCKS BY TIER. Locked treatments are temporary release states — the Unlock Plan artboard maps every hardcoded value to Tier 1 (src-only reads) or Tier 2 (CF-read constants), all fail-closed (absent = current behavior). Feature flags carry deliberately loud enable affordances.
