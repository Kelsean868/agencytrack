Planner & Scheduler — the day-planning + booking surface (new agent feature)

Digitizes the paper Weekly Planner booklet: agents book a week of appointments into time slots, work the day, and report results — and the plan pre-fills the report. An activity manager, not a CRM. Real activity types (P.C / S.C / A.I / F.F.I / C.I, Sales, free blocks), TTD, Trinidad names. Three flows tuned for speed: phone-day booking across a 2-month horizon, daily churn (cancel → reschedule / fill the freed slot), and the plan→report evening handoff. Mobile-first with a desktop week-booking board. Every screen in light + dark, with empty / loading / error states. Drag cards to reorder · click Focus (or ⤢) for fullscreen · ←/→ to step.
