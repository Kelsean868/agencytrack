Master Sheet — the reporting table as an explicit funnel

The 23-column sheet regrouped into 8 funnel stages. Collapsed by default — every stage shows only its KPI band — with a VIEW toggle (TOTALS ↔ + DETAILS) and per-stage +/− toggles in the group header to expand any stage's sub-columns in place. Stage KPIs close each group (parts → outcome) as tonal bands: neutral ink wash + 700 weight, teal reserved for the terminal KPI (API). Any column header sorts on click — ↓, then ↑, then a third click restores the default listing (YTD rank); the active sort also shows as a dismissible chip. A FILTERS panel (status · level · weekly report · no-log) joins the UNIT segmented control, with every active condition rendered as a chip with ×. Two-tier header and Agent + Status stay pinned through both scroll axes; a team totals row pins to the bottom. The small IK tag links FFI + CI Conducted to “Interviews Kept”.
