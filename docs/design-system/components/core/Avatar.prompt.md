Initials-tile avatar — the only avatar treatment allowed (never photos or generated faces).

```jsx
<Avatar initials="MS" />
<Avatar initials="AP" bg="#01696F" />
<Avatar initials="CR" shape="square" bg="#B07D1A" size={42} />
<Avatar initials="MS" ring />
```

Teal-tint circle default; solid `bg` (teal ramps #01696F/#018A91/#014E52/#013B3F, gold #B07D1A for CRO) turns text white; `square` for role tiles; `ring` marks leaders.
