Mono uppercase eyebrow microlabel — opens nearly every section/card on both surfaces.

```jsx
<Eyebrow>The agency loop</Eyebrow>
<Eyebrow>01 · Plan</Eyebrow>
<Eyebrow color="var(--gold)" star>This week · Leaderboard</Eyebrow>
<Eyebrow size="sm">YTD · Settled API</Eyebrow>
```

Teal by default; gold strictly for recognition/awards; `star` prefixes ★ for live/recognition content. Numbered form uses ` · ` separators.
