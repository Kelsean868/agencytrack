Status/label pill — tiny uppercase chip for statuses and badges.

```jsx
<Pill tone="success">On pace</Pill>
<Pill tone="warning">At floor</Pill>
<Pill tone="danger">Below</Pill>
<Pill tone="gold" solid>New</Pill>
```

Tones: teal (default/info), success/warning/danger (statuses), gold (recognition only), violet (list variety only), neutral. `solid` for filled badges.
