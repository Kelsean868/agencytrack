The brand's icon set — 24px-viewBox line icons, stroke 1.8, round caps (Lucide-style), copied from the codebase. Use the named exports; never emoji, never other icon fonts.

```jsx
<IconHome size={17} color="var(--teal)" />
<IconTrophy size={22} color="var(--gold)" />
```

Available: Home, Wizard, History, Chart, Target, Wallet, Medal, Shield, Bolt, Repeat, Book, Users, Grid, Settings, Search, Bell, Sun, Moon, ChevR, ChevD, ArrowR, Check, Alert, Trophy, Filter, Download, Plus, Clock (all prefixed `Icon`). Wrap new glyphs in `<Icon>` only if a needed symbol is truly missing.
