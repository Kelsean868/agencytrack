One sentence: a numeral that counts up from zero on load (KPIs, hero totals), degrading to the final value under reduced motion.

```jsx
<div style={{ font: '900 34px var(--display)' }}>
  TTD <CountUp value={532777} />
</div>
```

Formats with `en-US` thousands separators. Use `decimals` for percentages/ratios and `prefix`/`suffix` for units. Pair with the mono/display type for hero numbers; don't animate numerals in dense tables.
