# Marketing site UI kit

Faithful (condensed) recreation of the production agencytrack.app homepage, from `reference/index.html` in the attached codebase. Static HTML/CSS on the shared tokens (`styles.css`).

Included sections: sticky blurred nav, hero (glass phone stage + floating award/kiosk cards), feature marquee, stats, agency-loop steps, features bento, trust-gate ledger spotlight, audiences role grid, dark Kiosk/Meeting rhythm-break, resources cards, FAQ (details/summary with rotating +), final CTA, dark footer, WhatsApp FAB.

Deliberately omitted (present in production, not recreated): Calendly embed (replaced with a plain CTA button), the Caribbean team photo band (photo asset not provided), scroll-reveal/count-up JS, deep-dive rows (patterns are covered by the spotlight + modes sections), mobile hamburger nav, analytics.
